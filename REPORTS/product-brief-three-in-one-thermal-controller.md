## 一、产品定义

三合一控制器 = **压缩机控制器 ＋ 制冷系统 ECU ＋ 高压 PTC 控制器** 三合一，
对压缩机、风机、膨胀阀等热管理部件做集中控制。

**一句话定位**：新能源商用车热管理域控制器，用一个控制器代替原来三个独立控制器。

## 二、核心优势（vs 传统多控制器独立工作）

| # | 优势 | 说明 |
|---|------|------|
| 1 | 结构性降本 | 减少零部件数量、线束、控制接口 |
| 2 | 可靠性提升 | 系统故障率降低 |
| 3 | EMC 优化 | 电磁兼容性更好（一体化设计） |
| 4 | 集成度高 | 单控制器集中控制 |

## 三、核心技术参数

| 参数 | 规格 |
|------|------|
| 电压平台 | 额定 600V / 额定 800V（输入范围可按项目定制） |
| 控制器输入电压 | 250–750V DC / 600–1000V DC |
| 电池额定电压 | 600V / 800V |
| 电池工作电压 | 400–750V DC / 600–1000V DC |
| 低压供电 | 24V DC（16–32V DC） |
| 防护等级 | IP67 |
| 通信 | CAN 2.0（CAN 协议/CAN ID/波特率/控制逻辑可按项目定制） |
| 工作环境温度 | -40℃ ~ +60℃ |

## 四、控制逻辑

| 对象 | 控制依据 | 基本逻辑 |
|------|----------|----------|
| 压缩机转速 | 系统水温 / 系统目标温度 | 水温↑ → 转速↑；水温↓ → 转速↓ |
| 膨胀阀开度 | 过热度（Superheat） | 过热度↑ → 开度↑；过热度↓ → 开度↓ |
| 风机 | 冷凝器高压压力（压力传感器＋温度传感器） | 如高压压力达 ~13 bar → 启动冷凝风机；启停压力/转速曲线可按客户系统标定 |

## 五、定制能力

- 压缩机适配：可适配客户自有压缩机（需客户提供压缩机技术参数＋电机参数）
- 电压平台/输入范围：可定制
- CAN 协议/ID/波特率/控制逻辑：可定制
- 风机启停压力/转速曲线：可标定
